# ระบบรายงานทะเบียนหนังสือ

เว็บแอปพลิเคชันสำหรับ **นำเข้าไฟล์ทะเบียนหนังสือจาก Excel แล้วสรุปเป็นตาราง ค้นหา กรองข้อมูล พิมพ์รายงานเป็นกระดาษ A4 และบันทึกเป็น PDF**

ออกแบบสำหรับงานสารบรรณของหน่วยงานราชการไทย: ธีมสีกรมท่า–ขาว แบบ Modern Office Workspace,
ฟอนต์ Sarabun (ฝังมาในเครื่อง), เมนูด้านซ้าย, หัวตารางและป้ายกำกับเป็นภาษาไทยทั้งหมด

> **ทำงานในเบราว์เซอร์ของคุณทั้งหมด** — ไฟล์ Excel ที่เลือกจะถูกอ่านในหน่วยความจำของหน้าเว็บ
> **ไม่มีการอัปโหลดไฟล์ขึ้นเซิร์ฟเวอร์ ไม่มีฐานข้อมูลออนไลน์ ไม่มี Cloud ไม่มี Google Sheets และไม่ต้องใช้ API Key ใด ๆ**

---

## ⚠️ คำเตือนสำคัญ (อ่านก่อนใช้งาน)

1. **ข้อมูลอยู่ในหน่วยความจำของเบราว์เซอร์เท่านั้น**
   ข้อมูลที่นำเข้าจะหายไปทันทีเมื่อ **รีโหลดหน้าเว็บ (F5), ปิดแท็บ, ปิดเบราว์เซอร์ หรือเครื่องรีสตาร์ต**
   โปรแกรม **ไม่มี** การบันทึกอัตโนมัติลง localStorage หรือไฟล์ใด ๆ
   → **ต้องกด “ส่งออกข้อมูลเป็น Excel” หรือ “พิมพ์รายงาน / บันทึกเป็น PDF” ก่อนปิดหน้าเว็บทุกครั้ง**

2. **ไม่มีระบบล็อกอิน**
   ผู้ใดที่เปิดหน้าเว็บนี้ได้ จะใช้งานทุกฟังก์ชันได้ทันที (นำเข้าไฟล์ ดูข้อมูล ส่งออก)
   → **ห้ามนำเว็บนี้ไปเปิดให้เข้าถึงจากอินเทอร์เน็ตหรือเครือข่ายสาธารณะ** (เช่น ไม่ควร deploy บนโฮสติ้งสาธารณะ หรือเปิดพอร์ตให้ Wi-Fi สาธารณะเข้าถึง)
   ควรใช้เฉพาะบนเครื่องส่วนตัว หรือเครื่องในเครือข่ายภายในที่ควบคุมได้

3. **ไม่ควรใช้กับข้อมูลลับบนเครื่องสาธารณะ**
   ไฟล์ที่นำเข้าไม่ได้ถูกลบจากเครื่องของคุณ การใช้งานบนคอมพิวเตอร์ที่คนอื่นใช้ร่วมกันอาจทำให้ข้อมูลตกค้างในประวัติการดาวน์โหลดของเบราว์เซอร์

4. **ตรวจสอบปี พ.ศ. / ค.ศ. เสมอ**
   โปรแกรมจะเดาเองอย่างระมัดระวัง แต่ **ไม่สามารถยืนยันได้ 100%** ว่าเลขปีในไฟล์เป็น พ.ศ. หรือ ค.ศ.
   รายการวันที่ที่ไม่แน่ใจจะถูกรายงานเป็น **สรุปจำนวน “แถวที่ต้องตรวจสอบ”** และมีคำอธิบายในหน้าจับคู่คอลัมน์
   โปรดเทียบกับไฟล์ต้นฉบับก่อนนำไปใช้งานจริง (ระบบ **ไม่** เขียนคำเตือนใด ๆ ลงในคอลัมน์ “หมายเหตุ” — ช่องนี้ว่างเสมอทุกแถว)

5. **ระบบจะไม่แก้ไขข้อมูลแทนคุณ**
   คอลัมน์ที่ไม่มีข้อมูลจะเว้นว่างไว้ ไม่ดึงข้อมูลจากคอลัมน์อื่นมาแทน ไม่สลับลำดับ และไม่ลบข้อมูลทิ้งโดยไม่แจ้ง
   รายการที่ซ้ำจะถูกรายงานให้ทราบ แต่คุณเป็นผู้ตัดสินใจว่าจะข้ามหรือเก็บไว้
   การลบรายการต้องยืนยันทุกครั้ง และลบเฉพาะรายการที่ระบุ (ด้วย id ภายใน) เท่านั้น

6. **แสดงเฉพาะวันที่ ไม่แสดงเวลา**
   หากเซลล์ต้นทางมีทั้งวันที่และเวลา (เช่น `8 มกราคม 2567 16:30`) ระบบจะ **แสดงเฉพาะวันที่** (`8 มกราคม 2567`)
   ทั้งในตาราง ตัวอย่างรายงาน และรายงานพิมพ์/PDF โดยไฟล์ต้นฉบับบนเครื่องของคุณไม่ถูกแก้ไข

7. **ตัวอย่างไฟล์ในโฟลเดอร์ `sample/` เป็นข้อมูลสมมติ**
   ใช้สำหรับทดสอบระบบเท่านั้น ไม่ใช่ข้อมูลจริงของหน่วยงานใด

| รายการ | รายละเอียด |
| --- | --- |
| ระบบปฏิบัติการ | Windows 10 / 11 (ใช้งานได้บน macOS และ Linux เช่นกัน) |
| Node.js | เวอร์ชัน LTS (แนะนำ 20 ขึ้นไป) — ดาวน์โหลดที่ https://nodejs.org |
| เบราว์เซอร์ | Chrome หรือ Edge เวอร์ชันใหม่ (สำหรับฟังก์ชันพิมพ์เป็น PDF) |
| อินเทอร์เน็ต | จำเป็นเฉพาะตอน `npm install` เท่านั้น หลังจากนั้นใช้งานแบบออฟไลน์ได้ |

```powershell
node -v
npm -v
```

ถ้าแสดงเลขเวอร์ชัน (เช่น `v20.11.1`) แสดงว่าพร้อมใช้งาน

## วิธีติดตั้งและรันโปรเจกต์ (สำหรับ OpenCode)

### 1. ติดตั้ง dependencies

เปิดเทอร์มินัลที่โฟลเดอร์โปรเจกต์ แล้วรัน:

```powershell
npm install
```

> หมายเหตุ: โปรเจกต์นี้ใช้ SheetJS เวอร์ชัน `0.20.3` จาก CDN อย่างเป็นทางการของ SheetJS (ตามที่ระบุใน `package.json`) ไม่ใช่เวอร์ชันเก่าใน npm registry
> หาก npm ถามเรื่องการอนุญาตสคริปต์ติดตั้งของ `esbuild` ให้ตอบอนุญาต (`npm install-scripts approve esbuild`) — ดูหัวข้อ “แก้ปัญหาที่พบบ่อย” ด้านล่าง

### 2. รันโหมดพัฒนา (Development)

```powershell
npm run dev
```

จากนั้นเปิดเบราว์เซอร์ไปที่ **http://localhost:5173**

เมื่อรันแล้วจะเห็นหน้าเว็บ “ระบบทะเบียนหนังสือ” พร้อม **เมนูด้านซ้าย** 4 เมนู ได้แก่
**ภาพรวม / ทะเบียนหนังสือ / นำเข้าไฟล์ / สร้างรายงาน** โดยจะเปิดที่หน้า “นำเข้าไฟล์” ก่อน

### 3. สร้างไฟล์สำหรับใช้งานจริง (Production build)

```powershell
npm run build
npm run preview
```

- `npm run build` จะตรวจสอบ TypeScript (`tsc --noEmit`) แล้วสร้างไฟล์ static ไว้ในโฟลเดอร์ `dist/`
- `npm run preview` จะเปิดเซิร์ฟเวอร์ทดสอบไฟล์ที่ build แล้ว (โดยปกติที่ http://localhost:4173)
- โฟลเดอร์ `dist/` เป็นไฟล์ static ทั้งหมด สามารถเปิดจากเครื่องโดยตรงหรือก็อปปี้ไปเครื่องอื่นได้

> ⚠️ อย่านำ `dist/` ไปวางบนโฮสติ้งที่เข้าถึงได้จากอินเทอร์เน็ต เนื่องจากไม่มีระบบล็อกอิน (ดูคำเตือนข้อ 2)

## วิธีใช้งาน

แอปแบ่งเป็น **4 เมนูหลัก** บนแถบด้านซ้าย (คลิกสลับหน้าได้ทันที ไม่ต้องรีโหลด):

| เมนู | ใช้ทำอะไร |
| --- | --- |
| **ภาพรวม** | สรุปสถิติจากข้อมูลจริง กราฟรายเดือน และรายการล่าสุด |
| **ทะเบียนหนังสือ** | ตาราง 7 คอลัมน์ พร้อมค้นหา กรอง เรียงลำดับ และแบ่งหน้า |
| **นำเข้าไฟล์** | เลือกไฟล์ Excel/CSV เลือกชีต และจับคู่คอลัมน์ |
| **สร้างรายงาน** | กำหนดช่วงข้อมูล ดูตัวอย่าง และพิมพ์ A4 / บันทึกเป็น PDF |

ส่วนหัวด้านบนจะแสดงชื่อหน้า คำอธิบาย จำนวนรายการที่นำเข้าแล้ว และปุ่มลัด “นำเข้าไฟล์ Excel” / “สร้างรายงาน”

### นำเข้าไฟล์ — ขั้นตอนที่ 1: เลือกไฟล์

- **ลากไฟล์มาวาง** ในกรอบ หรือ **คลิกปุ่ม “เลือกไฟล์จากคอมพิวเตอร์”**
- รองรับ `.xlsx`, `.xls`, `.xlsm` และ `.csv` (ขนาดไม่เกิน 60 MB)
- ระบบจะแสดงชื่อไฟล์ ขนาดไฟล์ สถานะการอ่าน และจำนวน Worksheet ที่พบ
- ถ้าไฟล์ผิดประเภท ไฟล์ว่างเปล่า ใหญ่เกินไป หรือเสียหาย จะมีข้อความแจ้งข้อผิดพลาดเป็นภาษาไทย
- เมื่ออ่านสำเร็จ ระบบจะพาไปขั้นตอนที่ 2 ให้อัตโนมัติ
- **เปลี่ยนไฟล์ได้ตลอด** โดยไม่ต้องรีโหลดหน้าเว็บ (กด “เปลี่ยนไฟล์” หรือกลับมาที่เมนูนี้)

### นำเข้าไฟล์ — ขั้นตอนที่ 2: เลือก Worksheet และจับคู่คอลัมน์

1. **เลือก Worksheet** ที่ต้องการ (ถ้าไฟล์มีหลายชีต จะแสดงให้เลือก)
2. ดู **ตัวอย่างข้อมูลเต็ม** ของชีตนั้น (ก่อนจับคู่)
3. ระบบจะ **ตรวจหาหัวตารางให้อัตโนมัติ** — ไม่จำเป็นว่าหัวตารางต้องอยู่แถวที่ 1 เสมอไป (ชีตที่มีชื่อเรื่อง/วันที่อยู่ด้านบนก็ทำงานได้)
4. **จับคู่คอลัมน์** จากไฟล์ต้นทาง → คอลัมน์รายงาน 7 คอลัมน์ ตามลำดับ:

   | # | คอลัมน์รายงาน | ความหมาย |
   |---|---|---|
   | 1 | เลขรับ | เลขทะเบียนรับหนังสือ |
   | 2 | ที่ | เลขที่หนังสือ (document number) |
   | 3 | ลงวันที่ | วันที่ในหนังสือ |
   | 4 | จาก | หน่วยงานผู้ส่ง |
   | 5 | เรื่อง | ชื่อเรื่อง |
   | 6 | วันที่รับ | วันที่รับเข้าทะเบียน |
   | 7 | หมายเหตุ | หมายเหตุเพิ่มเติม |

   - ระบบจะ **เดาคู่ให้อัตโนมัติ** จากชื่อหัวตารางภาษาไทยและชื่อที่คล้ายกัน (เช่น “เลขที่”, “ที่หนังสือ” → `ที่`)
   - **ต้องจับคู่อย่างน้อย 1 คอลัมน์** จึงจะนำเข้าได้
   - คอลัมน์ที่ไม่ได้จับคู่จะ **เว้นว่าง** ไม่ดึงข้อมูลจากที่อื่นมาแทน
   - **คอลัมน์ “หมายเหตุ” จะว่างเสมอ** — ถึงแม้ไฟล์ต้นทางจะมีข้อความในคอลัมน์นี้ ระบบจะไม่นำมาใส่
     (ตามข้อกำหนดว่าช่องหมายเหตุต้องว่างทุกแถวในทุกบริบท: ตาราง ตัวอย่างรายงาน พิมพ์/PDF และไฟล์ที่ส่งออก)
5. **เลือกนโยบายปี (พ.ศ./ค.ศ.)**:
   - `ตรวจสอบอัตโนมัติ` (ค่าเริ่มต้น) — เดาจากค่าที่อ่านได้
   - `ยืนยันว่าเป็น พ.ศ. ทั้งไฟล์`
   - `ยืนยันว่าเป็น ค.ศ. ทั้งไฟล์`
   - หากการแปลงได้ปีที่ไม่สมเหตุสมผล ระบบจะเตือน
6. **ตัวเลือก “ข้ามแถวที่ข้อมูลไม่ครบ”** — ใช้ตัดแถวสรุปท้ายตารางหรือแถวรวมยอดออก (ปกติระบบข้ามแถวว่างให้อยู่แล้ว)
7. ตรวจสอบ **สรุปจำนวนแถว**: รวมทั้งหมด / อ่านได้ / แถวว่างที่ข้าม / แถวที่ต้องตรวจสอบ

**การอ่านวันที่** — ระบบรองรับ
- วันที่แบบ Excel serial number (แปลงเป็นวันที่ให้)
- วันที่แบบข้อความไทย เช่น `5 มกราคม 2567`
- รูปแบบ `12/01/2567`, `2567-01-20`
- **ตัดส่วนเวลาและอักขระส่วนเกินท้ายข้อความออก** (เช่น `8 มกราคม 2567 16:30`, `2567-01-08 00:00:00`) ให้เหลือเฉพาะวันที่
- ตัวเลขและข้อความถูกเก็บเป็น **ข้อความ** เพื่อรักษาเลขศูนย์นำหน้า (เช่น `0001`) ไม่ให้กลายเป็น `1`

### นำเข้าไฟล์ — ยืนยันการนำเข้าข้อมูล

ก่อนบันทึกจริง จะมีหน้าต่างยืนยันให้เลือก:

- **แทนที่ข้อมูลเดิม** — จะ **ลบข้อมูลเดิมทั้งหมดและใช้ข้อมูลใหม่** (มีการยืนยันซ้ำอีกครั้งก่อนลบจริง)
- **รวมกับข้อมูลเดิม** — เพิ่มข้อมูลใหม่ต่อท้ายข้อมูลที่มีอยู่

ระบบจะ:
- ตรวจ **รายการซ้ำ** และแสดงให้เลือกว่าจะ **ข้ามรายการซ้ำ** หรือ **เก็บไว้ทั้งหมด** (ไม่ลบให้เองโดยไม่ถาม)
- แสดง **จำนวนก่อนนำเข้า / เพิ่มเข้ามา / หลังนำเข้า** ให้ตรวจสอบ
- แสดงข้อความสรุปผลหลังนำเข้า

สามารถ **กลับไปเปลี่ยนไฟล์และนำเข้าซ้ำได้** โดยไม่ต้องรีเฟรชหน้า

### ภาพรวม (Dashboard)

- **การ์ดสรุป**: จำนวนรายการทั้งหมด, ช่วงวันที่ลงวันที่/วันที่รับที่ตรวจพบ, เดือนที่มีรายการมากที่สุด, จำนวนเดือนที่มีข้อมูล
- **กราฟแท่ง** จำนวนรายการแยกตามเดือน (เฉพาะเดือนที่แปลงวันที่ได้จริง)
- **ตารางรายการล่าสุด** 8 รายการที่มีวันที่ล่าสุดจากข้อมูลจริง
- ปุ่มลัดไปยังหน้าทะเบียนหนังสือและหน้าสร้างรายงาน

> ตัวเลขสรุปทุกตัวคำนวณจากข้อมูลที่นำเข้าจริงเท่านั้น ไม่มีการสร้างข้อมูลขึ้นเอง
> ถ้าข้อมูลวันที่ไม่พอสำหรับการสรุปรายเดือน ระบบจะแสดงข้อความว่าคำนวณไม่ได้ แทนการเดาตัวเลข

### ทะเบียนหนังสือ

- **ตาราง 7 คอลัมน์** ตามลำดับรายงาน พร้อมช่องลำดับ
- **เพิ่มข้อมูลด้วยมือ** — กดปุ่ม “เพิ่มข้อมูล” (ที่หัวหน้าเว็บหรือในหน้านี้) เพื่อเปิดฟอร์มกรอกครบ 7 ช่อง
  โดย **บังคับเฉพาะ “เลขรับ” และ “เรื่อง”** ช่องอื่นเว้นว่างได้ เมื่อบันทึกแล้วรายการจะปรากฏในตารางทันทีโดยไม่ต้องรีโหลด
  ระบบจะตรวจรูปแบบวันที่ก่อนบันทึก หากไม่ถูกต้องจะไม่ปิดฟอร์มและคงข้อมูลที่กรอกไว้ให้แก้ไข
- **ค้นหา** ได้จาก เลขรับ / ที่ / จาก / เรื่อง
- **กรองตามช่วงวันที่** (เลือกได้ว่าจะใช้คอลัมน์ “ลงวันที่” หรือ “วันที่รับ”) และ **กรองตามเดือน**
- **เรียงลำดับ** ตามวันที่, เลขรับ, ที่, จาก หรือ เรื่อง
- **แบ่งหน้า** และเลือกจำนวนรายการต่อหน้า (25 / 50 / 100 / 200)
- **ลบรายการ** — ทุกแถวมีปุ่มถังขยะในคอลัมน์ **“จัดการ”** (แยกไว้ทางขวาสุด ไม่รบกวนลำดับ 7 คอลัมน์)
  - ปุ่มจะปรากฏเมื่อชี้เมาส์ไปที่แถว หรือเมื่อโฟกัสด้วยคีย์บอร์ด (บนอุปกรณ์สัมผัสจะแสดงไว้ตลอด)
  - กดแล้วจะเปิดหน้าต่าง **“ยืนยันการลบรายการ”** แสดง เลขรับ / ที่ / เรื่อง ของรายการนั้น ก่อนยืนยัน
    หากยกเลิกจะไม่มีข้อมูลใดถูกแก้ไข
  - **ลบหลายรายการ** — ติ๊ก checkbox หน้ารายการ (หรือเลือกทั้งหน้าจากหัวตาราง) แล้วกด “ลบรายการที่เลือก N รายการ”
    ระบบจะแสดงจำนวนที่เลือกและถามยืนยันทุกครั้ง
  - การลบทำงานบน **state ที่ระบบใช้งานจริง** จึงอัปเดตตาราง ภาพรวม รายงาน และการส่งออก Excel ทันทีโดยไม่ต้องรีโหลด
  - ลบระบุด้วย **id ภายในที่ไม่ซ้ำ** ไม่ใช่เลขแถวบนหน้าจอ รายการอื่น (รวมถึงรายการที่มีเลขรับซ้ำกัน) จึงไม่ได้รับผลกระทบ
  - **ไม่แก้ไขไฟล์ Excel ต้นฉบับบนเครื่องของคุณ** และจะไม่ล้างข้อมูลทั้งหมดเพียงเพื่อลบรายการเดียว
- ปุ่ม **“ล้างตัวกรองทั้งหมด”** และ **“ล้างข้อมูลทั้งหมด”** (จะถามยืนยันก่อนลบ)
- ตารางเลื่อนแนวนอนได้เมื่อหน้าจอแคบ และข้อความยาวในคอลัมน์ “เรื่อง” จะตัดบรรทัดอัตโนมัติ ไม่ล้นไปทับคอลัมน์ข้างเคียง
- ข้อมูลที่เพิ่มด้วยมือจะ **รวมอยู่ในตาราง ภาพรวม รายงาน PDF และการส่งออก Excel** เหมือนข้อมูลที่นำเข้า และไม่ทำให้ข้อมูลเดิมหาย
- คอลัมน์ **“หมายเหตุ” ว่างทุกแถวเสมอ** ทั้งในตาราง ตัวอย่างรายงาน พิมพ์/PDF และไฟล์ที่ส่งออก
  (หัวคอลัมน์ยังแสดงตามรูปแบบรายงานเดิม) โดยไม่กระทบข้อมูลคอลัมน์อื่น

### สร้างรายงาน

- เลือก **เดือน / ช่วงวันที่ / คอลัมน์วันที่ / การเรียงลำดับ / คำค้นหา** สำหรับรายงาน
- กำหนด **ชื่อหน่วยงาน** (หัวรายงาน) และ **ชื่อรายงาน** ได้
- เลือกแสดง **ช่องลงนามท้ายรายงาน** พร้อมชื่อและตำแหน่งผู้ลงนาม
- **ตัวอย่างรายงาน A4** แสดงบนหน้าจอ ก่อนพิมพ์จริง
- ปุ่ม **“พิมพ์รายงาน / บันทึกเป็น PDF”** และปุ่ม **“ส่งออกข้อมูลเป็น Excel”**

**จำนวนแถวในรายงานจะตรงกับจำนวนรายการที่กรองได้เสมอ**
ในรายงานและหน้าพิมพ์จะแสดง **เฉพาะวันที่ ไม่มีเวลา** และ **ไม่มีเครื่องหมายเตือนใด ๆ**
คอลัมน์ **“หมายเหตุ”** ยังคงมีหัวคอลัมน์ตามรูปแบบรายงานเดิม แต่ **เซลล์ใต้หัวคอลัมน์ว่างทุกแถว**

## การพิมพ์เป็น A4 / บันทึกเป็น PDF

เมื่อกด “พิมพ์รายงาน / บันทึกเป็น PDF” จะเปิดหน้าต่างพิมพ์ของเบราว์เซอร์ ตั้งค่าดังนี้:

| หัวข้อ | ค่าที่แนะนำ |
| --- | --- |
| เครื่องพิมพ์ปลายทาง (Destination) | **Save as PDF** (หรือ “Microsoft Print to PDF”) |
| ขนาดกระดาษ (Paper size) | **A4** |
| แนวกระดาษ (Layout) | **Portrait (แนวตั้ง)** |
| ระยะขอบ (Margins) | ตามค่าเริ่มต้นของรายงาน (12–13 มม.) หรือเลือก **Default** |
| **Background graphics** | **เปิด (ติ๊ก ✓)** เพื่อให้สีหัวตารางติดมาด้วย |
| Headers and footers | ปิด (ไม่ต้องใช้ เพราะรายงานมีเลขหน้าในตัว) |

ระบบตั้งค่า `@page` เป็น A4 แนวตั้ง ระยะขอบ 12 มม. บน/ล่าง และ 13 มม. ซ้าย/ขวา ไว้แล้ว
หัวตารางจะ **ซ้ำทุกหน้า** (`table-header-group`) และแต่ละแถวจะไม่ถูกตัดครึ่งระหว่างหน้า
ข้อความในคอลัมน์ “เรื่อง” ที่ยาวจะ **ตัดบรรทัดอัตโนมัติ** โดยไม่ทับกับคอลัมน์ข้างเคียง
พร้อมแสดง **เลขหน้า “หน้า X จาก Y”** ในหัวรายงานของแต่ละหน้า

หากพบว่าฟอนต์ไทยไม่สวยหรือข้อความถูกตัด ให้ตรวจสอบว่าได้เปิด “Background graphics” และเลือกขนาดกระดาษเป็น A4 ตามตารางด้านบน

## ความเป็นส่วนตัวและความปลอดภัย

- ไฟล์ Excel/CSV ถูกอ่านใน **หน่วยความจำของเบราว์เซอร์** ด้วยไลบรารี SheetJS ที่รันฝั่งไคลเอนต์
- **ไม่มีการเรียก API ภายนอก ไม่มีการส่งไฟล์ขึ้นเซิร์ฟเวอร์ ไม่มีการส่งข้อมูลไปยัง Cloud หรือ Google Sheets**
- **ไม่มีการบันทึกข้อมูลอัตโนมัติ** ลง localStorage, IndexedDB หรือไฟล์ในเครื่อง
- ไม่มีคีย์ลับ (API key/secret) ใด ๆ ในโค้ด
- ไม่มีข้อมูลจริงของหน่วยงานอยู่ในซอร์สโค้ด — ข้อมูลใน `sample/` เป็นข้อมูลสมมติ
- เมื่อต้องการทดสอบว่าไม่มีการส่งข้อมูลออกจริง ให้เปิด DevTools (F12) → แท็บ **Network** แล้วใช้งาน — จะไม่พบคำขอ (request) ที่ส่งข้อมูลออกไป

**ข้อควรปฏิบัติ**
- ใช้บนเครื่องส่วนตัวหรือเครือข่ายภายในที่ควบคุมได้เท่านั้น
- ห้ามเปิดให้เข้าถึงจากอินเทอร์เน็ต เนื่องจากไม่มีระบบล็อกอิน
- ส่งออกข้อมูลเก็บไว้ทุกครั้งก่อนปิดหน้าเว็บ

## แก้ปัญหาที่พบบ่อย

**1. `npm.ps1 cannot be loaded because running scripts is disabled` (PowerShell)**
เรียกใช้ผ่าน `npm.cmd` แทน เช่น `npm.cmd run dev` หรือเปลี่ยนไปใช้ Command Prompt
หรืออนุญาตสคริปต์ด้วยคำสั่ง (รันใน PowerShell แบบ Administrator):
```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

**2. ติดตั้งแล้วค้างหรือถามเรื่องสคริปต์ของ `esbuild`**
npm บางเวอร์ชันจะบล็อกสคริปต์ติดตั้งของแพ็กเกจ ให้รัน:
```powershell
npm install-scripts approve esbuild
npm install
```

**3. เปิดหน้าเว็บแล้วไม่พบไฟล์ หรือพอร์ต 5173 ถูกใช้อยู่**
ปิดโปรแกรมที่ใช้พอร์ตนั้น หรือกำหนดพอร์ตใหม่:
```powershell
npm run dev -- --port 5174
```

**4. อ่านไฟล์ไม่สำเร็จ / ข้อมูลในไฟล์เพี้ยน**

- ตรวจสอบว่าไฟล์ไม่เสียหาย (ลองเปิดใน Excel)
- ถ้าเป็น `.csv` ที่มีอักษรไทย ให้บันทึกเป็น **UTF-8** หรือเปลี่ยนเป็น `.xlsx` แทน
- ถ้าหัวตารางไม่ถูกต้อง ให้ตรวจสอบตัวอย่างข้อมูลในขั้นตอนที่ 2 ว่าแถวหัวตารางตรงกับที่ระบบเลือกหรือไม่

**5. วันที่แสดงไม่ถูกต้อง หรือมีตัวเลขเวลาติดมา**
ตรวจสอบนโยบายปี พ.ศ./ค.ศ. ในขั้นตอนที่ 2 ว่าเลือกถูกต้อง แล้วดูสรุป “แถวที่ต้องตรวจสอบ”
ระบบตัดส่วนเวลาออกให้อัตโนมัติแล้ว หากยังพบรูปแบบวันที่ที่อ่านไม่ได้ ให้ส่งไฟล์ตัวอย่างมาเพื่อปรับปรุงการอ่าน

**6. พิมพ์เป็น PDF แล้วตัวอักษรไทยผิดปกติ**
ตั้งค่าในหน้าต่างพิมพ์: ขนาดกระดาษ **A4**, แนวตั้ง และ **เปิด Background graphics**

โปรเจกต์นี้สร้างขึ้นเพื่อใช้งานภายในหน่วยงาน ปรับแก้และนำไปใช้ต่อได้ตามความเหมาะสม
โปรดตรวจสอบผลลัพธ์กับไฟล์ต้นฉบับทุกครั้งก่อนนำข้อมูลไปใช้งานจริง
